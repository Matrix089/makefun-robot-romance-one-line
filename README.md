A tiny Python program that writes one original robot pickup line to /output/entry.txt for make.fun's Robot Romance: One-Line Pickup Lines for AI bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
